# Inference Engineer by Night

A small Astro blog published at `inferengrbynight.github.io`.

## Development

- `npm install` installs dependencies.
- `npm run dev` starts the local development server.
- `npm run build` creates the production site in `dist/`.
- `npm run preview` previews the production build.

Posts are Markdown files in `src/content/blog/`. The homepage lists them and individual posts are published at `/blog/<post-id>/`.
